# 线性神经网络及多层感知机
## 线性神经网络

其中一个输出的数学表达式为：
$$y_i = W_{i,1}x_1 + W_{i,2}x_2 + \dots + W_{i,d_{\text{in}}}x_{d_{\text{in}}} + b_i$$
  
W 为权重矩阵
x 为输入特征

### 实际用途
1. 特征融合: 把来自不同维度、不同分支或不同模态的信息整合成一个更具表达力的新特征
2. 特征拼接：$[x_1, x_2]$（特征直接排成一长串）
3. 决策层：例如：将 [房龄, 面积, 距离地铁距离] 融合预测出 房价（从 3 个特征融合为 1 个标量）。
4. 隐层特征提取：例如：输入层有 100 个低级特征，输出 256 个神经元（nn.Linear(100, 256)）。这 256 个神经元中的每一个，都各自把输入的 100 个特征以不同的权重融合了一遍，从而提取出了 256 种不同的高阶特征视角。

### 局限
1. 只能处理线性关系，无法处理非线性关系与拐点
2. 对于输入特征的位置 完全无法感知


## MLP（多层感知机，深度前馈神经网络）
起名字中的前馈是信息只会由输入层流向输出层，线性单向的流动关系，即一直向前。

经典组成为
1. 输入层
2. 隐藏层：即多个全连接层 + 激活函数，其被叫做是隐藏层的原因是外界无法观测和理解隐藏层参数的含义（确实理解不了）
3. 输出层

其相较于线性神经网络的改进为 引入了激活函数，可以表达非线性关系，是现代深度学习最基础的组件，在llm中身影随处可见。
