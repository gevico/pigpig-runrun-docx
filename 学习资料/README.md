# 学习资料

网络上的技术教程非常多，我在挑选学习资料的时候，更侧重于为大家提供宏观的把握和方向，而不是聚焦某一个具体的技术栈，因此对于某个具体技术的深度不足，这很正常。大家还需要在自己的方向上做专精的探索。

我并没有按我们的方向去删材料。每个人的技术背景不同、学习进度不同、分工不同。保持开放的技术视野对我们的团队有好处。

每一份材料都是别人为了自己的目的写的。他们的取舍、他们的侧重、他们觉得重要的地方，未必正好是我们要的，这个无可避免。读的时候心里记着我们自己的目标就好。
